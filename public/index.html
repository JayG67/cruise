Why this project matters

Built to demonstrate full-stack development with QA-driven engineering discipline.

This portfolio-grade application includes a RESTful API, PostgreSQL integration, automated data seeding, and a CI pipeline running unit and integration tests with enforced code coverage. It reflects real-world engineering practices focused on reliability, testability, and maintainability.
